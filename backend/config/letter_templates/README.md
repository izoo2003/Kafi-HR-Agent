# Employee letter templates

Official Word files:

- `appointment_letter.docx` — Appointment Letter
- `employment_contract.docx` — Appointment / Undertaking (contract)

Placeholders use `{{name}}` and are filled from the selected employee when HR creates the letter.

Employee fields used:

- Name, gender honorific (`Mr.` / `Ms.`), father name, CNIC
- Role title, joining date
- Monthly salary (total + the standard basic / house-rent / fuel-medical-mobile split)
- Phone and email
- Professional and blood-relative references (contract)

Company address, timings, and policy wording stay as in the official templates.
