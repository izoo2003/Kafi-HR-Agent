# Credentials folder

Place these files here (never commit them — already covered by `.gitignore`):

- `google_oauth_client.json` — OAuth client downloaded from Google Cloud Console (Desktop App type). Used for both Gmail and Google Sheets/Drive access.
- `gmail_token.json` — auto-generated on first run after you complete the OAuth consent flow for Gmail.
- `form_token.json` — auto-generated on first run after you complete the OAuth consent flow for Sheets/Drive (Google Form responses).

See the main `README.md` for the full setup walkthrough.
